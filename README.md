# 💬 Chat Application

A modern real-time chat application built with **React.js** and **Socket.io**. It provides a fast, responsive, and interactive messaging experience with real-time communication and user presence tracking.

---

## 🌐 Live Demo

 **You can use 'Family' as group id for testing**
 
🔗 **Live Website:** [https://your-live-demo-link.com](https://chating-hub.netlify.app/)

---

## ✨ Features

- 🔐 Unique User Login
- 💬 Real-time Messaging
- 🟢 Online / Offline Status
- 📱 Responsive UI (Mobile Friendly)
- ⚡ Fast and Interactive Chat Experience

---

## 🛠️ Tech Stack

### Frontend

- React.js
- Tailwind CSS
- Socket.io Client

### Backend

- Node.js
- Express.js
- Socket.io

## ⚙️ Installation & Setup

### 1. Clone the Repository

```bash
git clone https://github.com/Saqib-Bahadur/chat-application.git

cd chat-application
```

---

### 2. Install Dependencies

#### Backend

```bash
cd backend
npm install
```

#### Frontend

```bash
cd frontend
npm install
```

---

### 3. Run the Application

#### Start Backend

```bash
cd backend
npm start
```

#### Start Frontend

```bash
cd frontend
npm run dev
```
