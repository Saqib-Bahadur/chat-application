# Chat Application (MERN Stack)

A real-time chat application built using the MERN stack. This project demonstrates modern full-stack development with real-time communication features.

---

##  Features

* Unique User (Login)
* Real-time Messaging (Socket-based)
* Online / Offline Status
* Responsive UI (Mobile Friendly)
* Fast and Interactive Chat Experience

---

## Tech Stack

### Frontend

* React.js
* Tailwind CSS
* Socket.io-client

### Backend

* Node.js
* Express.js
* Socket.io

## ⚙️ Installation & Setup

### 1. Clone the repository

```
git clone https://github.com/Saqib-Bahadur/chat-application.git
cd chat-application
```

---

### 2. Install dependencies

#### Backend

```
cd backend
npm install
```

#### Frontend

```
cd client
npm install
```

---

### 3. Run the application

#### Start Backend

```
cd backend
npm start
```

#### Start Frontend

```
cd client
npm run dev
```
